## 自动检查

- `npm run lint`：严格类型与未使用代码检查通过。
- `npm test`：8 项测试通过，覆盖章节、来源、展位、路线连通、眼高、坡度及线性采样。
- `npm run check:routes`：当前导出 GLB 检查通过，模型 SHA-256 与详细结果存于 `output/route-audit.json`。
- `npm run build`：生产构建通过。Vite 提示 Three.js 主包超过 500 kB；这是体积提醒，非构建失败。

路线检查只覆盖导出的可行走路线；它不是全场自由移动、角色跳跃或任意碰撞系统的认证。媒体缺失和网络中断提示已实现，但本次没有对全部加载失败组合做故障注入测试。

## 性能与资产

桌面 Codex 浏览器，1280×800，精细模式像素比上限1.7：入口、中庭、侧厅及夹层的稳定观察段约60 FPS。390×844窄屏也观察到约60 FPS，但这仍使用桌面 GPU，不代表真实手机性能。帧率按实际经过时间统计，动画步长单独限制。

GLB约5.1 MiB，静态光照PNG约14 MiB，Blender源文件约6.1 MiB；原片约183 MiB，保留本地并按需播放。主JS包约610 kB、gzip约161 kB。初始静态资产体积仍偏大，公开上线前可以继续做图集压缩、模型压缩和缓存优化。

## 美术和产品限制

灰白材质、天窗、深色地面与建筑探索结构已经落地；局部烘焙边缘、薄墙接缝和墙面的细腻程度仍不如概念图。个别光斑亮部较平，静态漫反射方案不具备动态间接光或镜面地板反射。四视角概念图中的建筑透视被整理为一套真实连通布局，并非逐像素还原。

内容目前只有一场真实访谈，其他两个独立展厅为待加入。代码提供分访谈播放进度和展位引用，但尚未用第二条真实访谈验证跨期内容体验。没有后台、自动字幕导入、第三人称人物或多人功能。
