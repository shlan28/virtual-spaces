# 云海思想群岛

这是一片可探索的访谈账号空间。地形、石拱、道路、展台和植被均为三维对象；云海远景使用生成的全景纹理。场景目前接入一条真实访谈、八个精选时间片和三组编辑整理的观点，其他展位明确标记为待加入。

## 启动

在本目录运行：

```sh
npm ci
sh scripts/prepare-media.sh
npm run dev -- --port 4173
```

打开 <http://127.0.0.1:4173>。媒体准备脚本默认读取 `/Users/lu/Desktop/01ea90455678084a01037003a04415d32d_259.mp4`；也可以把其他路径作为第一个参数传入。已有本地媒体时无需重复准备。

```sh
npm run build
npm run preview -- --port 4174
npm test
```

Node.js 建议 22.12 以上。已在本机 Node 25.8 与 Blender 5.2 上验证。

## 怎样浏览

- 底部入口、石拱、访谈、山顶、全景按钮可直接抵达不同位置。
- 拖动空白处观察；WASD 按当前视角在实体地面上自由移动，上下键仍可前进或后退。
- 在访谈平台直接横向拖动切片，或用“上一片／下一片”按钮浏览；左右键也可拨动。浏览阶段保持静音且不自动播放。
- 点击切片或“查看片段”，展开原片与摘要。点击播放按钮从对应时间开始；播放器原生时间轴可定位到全片任意位置。
- 点击观点碑或关系节点，阅读编辑概括并进入来源片段。
- 关闭面板或按 Escape，会暂停视频并恢复进入面板前的相机位置。
- 右上角可切换精细／流畅画质。流畅模式减少草量和实时阴影，限制像素比。

## 资产与文件

- `assets/cloud-world.blend`：独立 Blender 源场景，保留地形、天然石拱、道路、平台、相机和灯光。
- `public/models/cloud-world.glb`：约 2.2 MB 的网页地形资产。
- `public/models/world-layout.json`：植被和路线共用的场景参数。
- `scripts/build_scene.py`：可重复执行的 Blender 制作脚本；每次创建独立场景，不删除用户已有场景。ROOT 根据脚本所在位置推导，整体移动目录后无需修改；通过 MCP 执行时需将 `__file__` 设为脚本完整路径。
- `public/textures/cloud-panorama.png`：内置 imagegen 生成的云海天空纹理，约 1.7 MB；不是完整空间的平面替代图。
- `public/media/chapter-atlas.jpg`：从用户视频截取的章节缩略图图集。
- `public/media/interview.mp4`：本地原片副本，约 183 MB，已排除 Git。
- `src/content.ts`：访谈、时间片、观点与来源关系。
- `output/playwright/`：实际浏览器截图。
- `validation.md`：验证记录与运行限制。

Blender 脚本可由 MCP 执行，也可以使用：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/build_scene.py
```

导出文件包含 Blender 制作的空间骨架。植被、晶体、天空、水面、视频与信息界面由网页运行时添加，因此单独打开 `.blend` 不会出现全部网页内容；GLB 也不是含交互逻辑的完整应用。

## 内容与视觉边界

章节范围来自已整理的 OCR 内容地图，属于约略定位，未宣称逐字转录或每条观点都已完成发言归属精校。三组观点明确标为编辑整理。卫星展位可引用同一期不同片段，不把同一来源伪装成多期节目。

这是风格化、程序建模的可运行版本。已经具备参考图的群岛、石拱、步道、云海、粉色晶体和分散展区，但植被、岩壁雕刻和自然光细节尚未达到生成概念图的美术精度。远景云海是背景纹理与少量动态云层，不是可进入的体积云。

已编写移动端窄屏样式，但当前浏览器的测试视口覆盖未生效，真实窄屏布局和手机 GPU 性能尚未验证。漫游采用路线移动和观察镜头，不具备完整角色物理、重力或任意地形攀爬。当前没有多人同步、账号管理或内容上传后台。

此目录与峡谷、天窗馆共享上级 `virtual-spaces` Git 仓库。代码、GLB、图集、天空纹理进入版本管理；视频、Blender 源文件、依赖、构建产物和运行截图留在本地。
