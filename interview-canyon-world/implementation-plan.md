# 峡谷访谈空间实施方案

## 1. 要交付的体验

在独立目录 `interview-canyon-world` 制作可本地运行的三维访谈账号空间，保留现有 `interview-cloud-world`，两版互不覆盖。

空间是一座藏在浅色峡谷中的内容博物馆。用户从较窄的入口沿暖色光路进入，转过岩壁才逐渐发现访谈洞室、观点刻墙、水边装置和高处展台。重要信息可以直接阅读，访谈视频分布在不同位置；用户可以沿路探索，也能直接跳到想看的内容。

参考图：[峡谷概念图](/Users/lu/.codex/generated_images/01a0752f-b78c-7542-be89-8aacf2610f39/exec-2224fc60-61aa-434e-b3f1-a61e663abc74.png)。保留浅色层岩、暖光曲路、洞室视频、浅水倒影、镜面门和分散的信息装置。图中人物、文字、年份和嘉宾排列不作为真实内容依据。

账号级内容原则沿用 [空间设计](/Users/lu/Desktop/achoverse/achoverse-marketing/docs/robotics-spatial/space-design.md)。该文档早期建议的开放全景布局，在本版本由用户后续确认的遮挡、转弯和探索结构替代；多期内容、来源关联和半圆切片要求继续保留。

## 2. 空间布局与探索顺序

| 位置 | 看到与读到什么 | 操作及去向 |
|---|---|---|
| 狭口入口 | 账号／节目标识、最近一期入口、延伸到岩壁背后的光路 | 前进进入首个弯道；可直接定位访谈 |
| 首个弯道 | 左侧洞室与局部水面，远处只露出镜面门的一部分 | 继续走或进入洞室，尚不能看到所有展区 |
| 访谈洞室 | 一期访谈的标题、嘉宾、独立半圆切片、当前段落摘要 | 拨动切片、定位原片、阅读关联重点 |
| 观点岩壁 | “平台为何投入软件”等局部关系与分类 | 点击查看解释及来源，回到相应时间片 |
| 水边对照区 | 两块石碑呈现“大客户与创新客户”的不同作用 | 比较两侧信息，进入对应来源 |
| 镜面转折区 | 镜中反射峡谷与光路，真实通路绕过镜面 | 转弯后发现下一展位；镜面不承担传送功能 |
| 高处展台 | 另一处独立访谈展位及峡谷局部俯视 | 首版标明待加入；可返回低处和入口 |

上述展区属于同一连续空间。洞室入口、峡谷曲率和高差共同控制可见范围，不用突然显示／隐藏整片内容制造探索感。全景是辅助检查和定位视角，不是默认进入视角。

一期访谈可以关联多处重点装置，但各处始终显示同一来源身份。后续多期访谈以稳定展位 ID 接入；增加内容先扩展局部主题集合，再增加空间支路，不要求每一期重建整座峡谷。

## 3. 视频与信息怎样使用

### 半圆切片

每个切片是独立竖直平面，沿半圆排列，切片之间没有连接面。横向拨动时，邻片沿弧线让开，当前片露出标题、预览画面和时间范围；不做物理唱片抽取动作，也不在中央设置巨屏。

复用云岛版的章节与单活动视频机制，但重新校准半圆半径、间距和镜头距离，检查洞壁是否遮挡切片。切片拖动优先处理，拖动过程中镜头保持稳定。提供上一片／下一片按钮和键盘操作；拨动不自动播放，点击后打开播放面板，再明确播放。

连续时间轴能定位原片任意时间，精选章节之间的空档仍可观看。关闭播放器暂停声音，恢复探索镜头；重新进入同一期时保留播放进度，明确选择另一个章节时定位该章节。远处只显示静态预览，同一时刻只有一个活动音源。

### 空间中的重点

常用观察距离能直接读到问题、核心概括和来源身份，完整说明按需展开。文字由运行时生成，避免把正文烘焙进低分辨率岩石贴图。所谓“刻墙”以贴近岩面的文字、浅浮雕感边框和光线构成，首版不逐字雕刻网格。

优先使用现有内容地图中的材料：

- 关系墙：软件工具、开发效率与量产支持，约 29:44–34:08。
- 分类墙：地瓜内部 1.0／2.0／3.0 业务分类，约 20:00–24:04；不画成行业必经升级路线。
- 对照碑：大客户带来订单、创新客户帮助探索需求，约 50:56–55:44；不用概念图中未经来源支持的“效率 vs 价值”。

时间线优先呈现访谈中的讨论顺序；只有核实的事件才显示真实年份。以上时间是已有 OCR 整理的约略范围。展示前抽查对应片段，未核实的发言归属不标成确定引语，编辑概括明确标注。

目前只有一条真实访谈。另一洞室或高处展位标记为“待加入访谈”，不伪造嘉宾和跨期观点。首版验证多展位结构；真实跨期理解效果需要以后补充真实内容验证。

## 4. 视觉制作目标

这一版以浅色砂岩、暖光和水面为主，避免云岛版大量程序植被造成的美术分散。默认视角保持参考图的浅米灰岩壁与粉暖天空，洞室有局部暖光，但不把整个场景压暗来掩盖细节。

美术与功能分别验收：能行走、点击和播放不等于接近参考图。先完成入口弯道、左侧洞室和一段水面的精细样板，再把已验证的石材、光照和尺度应用到后续峡谷。此顺序是实施内部的质量检查，不是只交付局部的范围缩减。

近景岩壁必须有可辨认的大体块、中尺度层理和细小表面起伏。不能只把同一噪声贴在光滑墙体上，也不能用一圈相同岩石重复拼满视野。洞口有真实进深与顶壁，路面与水岸有清楚厚度和衔接。

目标是可交互且接近参考图气质与主要构图的网页场景；不承诺生成图的逐像素还原。最终用真实浏览器截图呈现成果，不以 Blender 离线渲染或生成图代替运行结果。

## 5. 实现与资产安排

### 工程边界

采用独立 Vite + TypeScript + Three.js 工程。从云岛版复制并适配内容、播放器、切片和界面模块，不直接修改云岛文件，也不在这轮抽取跨项目公共包。新版本默认使用 `http://127.0.0.1:4175/`，启动前检查端口，保留云岛正在使用的 4173。

内容配置采用访谈 ID、章节 ID、重点 ID 和展位 ID 分离的结构。展位引用访谈，重点引用来源章节；媒体元素与播放进度按访谈管理，避免未来多期内容仍被写死在一个全局视频里。

### Blender 与 Three.js 分工

Blender 制作峡谷岩壁、洞室、路面、岸边、展台、石碑和镜面框架，保存独立源文件并导出 GLB。通过 MCP 先检查当前场景，再创建独立命名场景；不删除或覆盖用户原有场景。制作脚本从自身路径推导工程目录，减少硬编码绝对路径。

Three.js 负责光照、局部辉光、水面与镜面效果、可读文字、切片动画、导航和视频。模型命名约定区分岩石、步道、石碑与镜框，运行时按名称挂接材质与交互。路线、展位锚点、观察点和遮挡体写入布局数据，与 Blender 使用同一坐标约定。

岩石采用兼容网页的基础色、法线与粗糙度贴图，复杂 Blender 节点需要烘焙；环境遮蔽可烘焙到独立贴图并检查 UV。不能假设 Blender 灯光、程序纹理和材质节点直接导出就能保持相同效果。纹理制作／选取后记录来源及使用条件；需要付费购买时另行说明，不默认购买。

### 光照、反射与运行开销

以环境光、一个主要方向光和少量洞室局部光建立明暗关系。光路同时使用发光材质、受控辉光以及周围石材的暖色照明；发光材质本身不会自动照亮路面。

水面和竖直镜面分别使用受限分辨率的平面反射，控制可见区域、更新频率和递归，避免水与镜无限互相渲染。流畅模式使用简化环境反射、降低阴影与像素比；文字保持可读。若反射开销超预算，优先保留近处最显眼的反射并记录降级效果。

远处岩壁简化几何；重复碎石使用实例化。视频延迟到明确操作时加载播放数据，首屏不完整下载 183 MB 原片。桌面以持续流畅探索为目标，固定测试视角记录分辨率、画质、帧率和加载体积；低于 30 FPS 的持续停顿视为需处理的问题，不能只引用空场景峰值。

### 导航与操作

使用沿路线前进／后退和局部观察，提供目的地跳转、返回入口及辅助全景。跳转采用安全观察点和路线过渡，避免直线飞穿岩壁。鼠标、键盘和触摸都有明确控制；点击检测考虑地形遮挡，不能隔着墙点中展品。

首版不加入第三人称人物、角色动画、任意地形攀爬、多人同步、账号后台或自动导入整账号。这些不影响当前探索与观看的验证。

## 6. 实施顺序

1. 建立独立工程，适配现有内容和播放模块；完成入口到高处展台的空间比例与遮挡布局。
2. 用 Blender 打磨首个弯道、洞室、水岸，导入网页校准石材、暖光、反射和镜头；检查近景质感后再扩展。
3. 补全曲路、镜面转折、关系墙、对照碑和高处展位，保证沿路能逐次发现内容。
4. 接入半圆拨动、视频定位、重点来源、状态恢复及画质降级。
5. 在真实浏览器逐项验收，修复问题，保存多视角截图、启动说明和已知限制，提交代码。

如实施复杂度需要并行工作，按用户 AGENTS.md 的要求先说明，再由独立子任务处理界面适配或视觉检查；主场景、坐标布局及 Blender 资产由同一主线维护，避免多人同时修改同一模型。

## 8. 验收标准

| 检查项 | 通过条件 |
|---|---|
| 探索感 | 入口看不到完整峡谷和所有展位；转弯后出现此前被岩壁遮挡的内容 |
| 环境质感 | 近景可见层理、凹凸、洞口厚度与接地阴影；有明亮环境与暖色局部照明的层次 |
| 参考构图 | 首弯视角同时包含左侧洞室、弯曲光路、浅水与远处镜面；其余视角揭示完整空间 |
| 信息可读 | 常用视角能读到重点含义与来源，细节面板可完整阅读；不使用概念图伪文字 |
| 切片交互 | 独立半圆排列，逐片拨动有邻片让开；没有连片、误转镜头或自动发声 |
| 视频定位 | 选片定位、连续拖动、暂停、关闭、恢复及换片均正确；无重复音源 |
| 来源联动 | 重点进入对应访谈章节；回退恢复原观察位置；待加入内容不会打开伪造媒体 |
| 导航 | 所有展区可达，无必经路线穿墙；遮挡后的展品不可隔墙点击 |
| 兼容与性能 | 类型检查、生产构建及必要内容测试通过；桌面记录实际帧率与加载情况；窄屏验证记录实际视口 |
| 异常处理 | 模型或媒体失败有可理解提示；离开播放器后停止声音，重复进入不累积资源 |

移动端样式通过不等于手机性能通过。若工具不能改变实际视口，或缺少真实手机测试条件，明确记录未验证范围，不把桌面截图当成移动端验收。
